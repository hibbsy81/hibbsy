Data: Open-Meteo — two sources are fetched: Open-Meteo's own "Best Match" (its automatic pick of the highest-resolution model available for the location, shown by default), and the NOAA GFS model directly. Switch between them with the source selector above the table. Wind speed in knots, direction is the compass heading the wind is blowing from, temperature in °C. Heights are shown above DZ level (AGL), using the model's own surface elevation for that point — not above sea level. Altitudes between the underlying model's native pressure levels are linearly interpolated (by vector, using each level's actual geopotential height for that forecast hour) to give values every 1,000 ft — treat them as a smooth estimate, not an independent measurement. QNH shown is the lowest forecast mean-sea-level pressure for the selected calendar day — a conservative reference for altimeter setting, not a substitute for an actual QNH read from your DZ. MGRS parsing covers standard UTM zones/bands only (not the Svalbard/Norway irregular zones or UPS polar zones). Always cross-check against a live winds-aloft briefing and your DZ's actual observations before jumping. Planning reference only.
